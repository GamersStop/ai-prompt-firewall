# Contributing to AI Prompt Firewall (`ai-prompt-firewall`)

First off, thank you for considering contributing to `ai-prompt-firewall`! 🎉 

`ai-prompt-firewall` is an open-source, developer-first AI prompt security middleware built to detect and remediate sensitive secrets and PII before reaching LLMs. We welcome contributions of all kinds—from bug reports and documentation fixes to new security pattern rules and provider integrations.

---

## 🤝 Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free environment for all contributors. Please treat every community member with respect, empathy, and constructive feedback.

---

## 🐞 Reporting Bugs

Before creating a bug report, please check the existing [GitHub Issues](https://github.com/GamersStop/ai-prompt-firewall/issues) to ensure the bug hasn't already been reported.

When submitting a bug report, please include:
1. **Clear Summary:** A concise title and description of the issue.
2. **Environment Details:** Node.js version, npm version, OS, and `ai-prompt-firewall` version.
3. **Reproduction Steps:** A minimal code snippet demonstrating the problem.
4. **Expected vs Actual Behavior:** What you expected to happen versus what actually occurred.

> [!IMPORTANT]
> **Security Vulnerability Reporting:** If you discover a critical security vulnerability or zero-day bypass vector, please **do not** open a public issue. Instead, report it privately to the maintainers at `dreainno@gmail.com`.

---

## 💡 Suggesting Features or New Patterns

We love community suggestions for expanding built-in security patterns (e.g., new cloud API keys, OAuth tokens) or adding provider middleware wrappers!

When proposing a new pattern or feature:
- Describe the use case and real-world scenario.
- For new regular expression rules, provide examples of valid secret tokens and explain how false positives are prevented.
- Ensure any proposed regular expressions are optimized for performance and free of catastrophic backtracking (ReDoS) risks.

## 💻 Local Development Setup

### Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher

### Step-by-Step Setup

1. **Fork and Clone the Repository:**
   ```bash
   git clone https://github.com/GamersStop/ai-prompt-firewall.git
   cd ai-prompt-firewall
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Verify the Build & Test Suite:**
   ```bash
   npm run build
   npm test
   ```

## 🏗️ Repository Architecture

Understanding the project structure makes navigating the codebase simple:

```
ai-prompt-firewall/
├── src/
│   ├── index.ts                # Main public export entry point
│   ├── core/
│   │   ├── ai_scanner.ts       # Core scanner engine & PromptFirewall factory
│   │   ├── patterns.ts         # Built-in regular expression dictionary
│   │   ├── types.ts            # TypeScript interface definitions
│   │   ├── errors.ts           # Typed error hierarchy (PromptBlockedError, etc.)
│   │   └── validators.ts       # Runtime validation guards & type narrowing
│   ├── middleware/             # Provider-specific wrappers
│   │   ├── openai.ts           # OpenAI completion/chat wrapper
│   │   ├── anthropic.ts        # Anthropic Claude prompt wrapper
│   │   └── langchain.ts        # LangChain prompt template wrapper
│   └── cli/
│       └── index.ts            # CLI binary executable (npx ai-prompt-firewall)
├── tests/                      # Vitest unit and integration test suites
│   ├── ai_scanner.test.ts
│   ├── middleware.test.ts
│   └── core.test.ts
├── examples/                   # Executable usage & pattern test scripts
├── dist/                       # Compiled ESM and DTS output generated by tsup
└── package.json
```

| Task | Command | Description |

## 📜 Pull Request Guidelines

To maintain package quality and reliability, all Pull Requests (PRs) must satisfy the following criteria:

1. **Branch Naming:** Use descriptive branch names:
   - `feat/add-datadog-pattern`
   - `fix/openai-key-regex-boundary`
   - `docs/update-readme-examples`
2. **Keep PRs Focused:** Aim for small, single-purpose pull requests rather than large sweeping changes.
3. **Include Unit Tests:** Any new feature, pattern addition, or bug fix **must** include accompanying unit tests in `tests/`.
4. **Pass Automated Checks:**
   - All tests must pass (`npm test`).
   - The build must compile without errors (`npm run build`).
   - Code must be formatted cleanly (`npm run format`).
5. **No Runtime Dependencies:** `ai-prompt-firewall` maintains a **0-runtime-dependency** posture. Do not add runtime dependencies under `"dependencies"` in `package.json`.
